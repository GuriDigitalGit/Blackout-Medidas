# Blackout Medidas

Simulador de tamanho de kimono da Blackout Jiu-Jitsu.

O aluno informa altura e peso e o app indica o tamanho ideal do kimono, com uma segunda opção para provar, explicação da indicação e dicas sobre encolhimento.

## Como usar

Acesse o link do GitHub Pages do repositório pelo celular ou computador. No celular, dá para adicionar à tela inicial e abrir como aplicativo.

## Funções

- Simulação para adulto, feminino e infantil
- Altura em centímetros ou metros (175 ou 1,75)
- Opções de caimento, kimono pré-encolhido e envergadura
- Histórico de simulações salvo no aparelho
- Tabela de medidas editável para ajustar à marca revendida

## Estrutura

Todo o app está no arquivo `index.html`, sem dependências para instalar.

## Observação

As medidas padrão são médias de mercado. O tamanho final deve ser confirmado provando a peça, com a tabela oficial do fabricante.
